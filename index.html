SARkart: Linux SAR file viewer and sysstat analyzer

SARkart turns the text output of sar -A into interactive charts for CPU, memory, swap, disk I/O, network and load average, and runs deterministic bottleneck checks so you can see what went wrong and when. Everything is parsed in your browser — your SAR files are never uploaded.

Features

  • Up to 20× faster than sarchart: a 313 MB RHEL 9 SAR file loads in about 2 seconds
  • Diagnostic dashboard ranking CPU wait and steal, load, memory, swap, disk saturation and network errors
  • Incident-window triage and a copy-ready ticket summary for support cases
  • Time-of-day heatmaps, per-core CPU, per-device disk and per-interface network charts
  • PDF export, date-range filtering, dark and light themes
  • Works with sysstat output from RHEL, SUSE and Ubuntu

How to generate a SAR file

sar -A -f /var/log/sa/sa$(date +%d) > /tmp/sar_$(uname -n).txt

Then open SARkart and drop the .txt file onto the page. SARkart requires JavaScript.
